# Retail Store Sales Analysis Using Python

## 1. Project Overview

This project focuses on cleaning, exploring, and analyzing retail store transaction data using Python. The objective is to identify sales patterns, understand category performance, examine payment preferences, and generate meaningful business insights through data analysis and visualization.

## 2. Dataset Overview

- Total Records: 12,575 transactions
- Original Columns: 11
- Data Type: Retail transaction data
- Period: 2022–2025

## 3. Project Objectives

- Identify product categories generating the highest sales.
- Analyze monthly sales trends.
- Identify the most frequently used payment methods.
- Compare sales across online and in-store locations.
- Examine sales patterns based on discount status.
- Identify and handle missing values and outliers.

## 4. Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 5. Data Cleaning and Preparation

- Inspected dataset structure and data types.
- Identified missing values and calculated missing-value percentages.
- Checked for duplicate records.
- Handled missing categorical and numerical values using mode, mean, and median.
- Converted transaction dates into datetime format.
- Detected outliers using the Interquartile Range (IQR) method.

## 6. Exploratory Data Analysis

### Univariate Analysis
- Distribution of transaction amounts.
- Monthly sales trends.
- Payment method preferences.
- Online vs. in-store transactions.

### Bivariate Analysis
- Total sales by product category.

### Multivariate Analysis
- Sales comparison by location and discount status.

## 7. Key Business Insights

- Butchers generated the highest recorded category sales, totaling 204,140.
- Milk Products recorded the lowest category sales, totaling 182,740.50.
- Cash was the most frequently used payment method, with 4,263 transactions.
- Online and in-store transactions showed a nearly balanced distribution.
- Online transactions with discounts recorded the highest aggregate sales.
- Monthly sales fluctuated throughout the observed period.

## 9. Conclusion

This project demonstrates the use of Python for analyzing retail transaction data and extracting meaningful business insights. It highlights the importance of data cleaning, exploratory analysis, and visualization in understanding sales performance and supporting data-driven business decisions.
